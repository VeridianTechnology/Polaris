# Glub Script — version 1

An original 26-glyph alphabet, written left to right. Each glyph maps to one
Latin letter A–Z. The shapes use diamonds, open gates, stems, and intersecting
lines. Names such as Origin, Tide, and Orbit help people remember the forms;
they are not word meanings or a new vocabulary.

`alphabet.js` is the authoritative mapping. `alphabet.svg` is the printable
reference sheet. All art is code-native SVG, so it remains sharp at any size.

Type normal text or use the sidebar's letter picker. The board can show
English, Glub Script, or both. Uppercase and lowercase share a glyph; the
stored text preserves exact case, punctuation, numbers, spaces, emoji, and
other writing systems. Screen readers read the original text. Search and
board exports continue to use plain text.

This is a writing system for English, not a newly invented spoken language,
an encryption scheme, or a claim that language models understand new glyphs.
Gemini Notebook should receive the plain-text research material. A future
grammar and vocabulary can be developed separately without breaking drafts.
