# Gemini Notebook setup

Selected by the owner: option 1, Gemini Notebook. API integration remains off.
The owner’s notebook is linked:
https://notebook.google.com/notebook/ce1f1c9e-90e3-428e-bc41-679ae8f92d80
Editing access is unverified: the available fresh browser reaches Google's
sign-in screen, and this session exposes no authenticated Notebook connector.

1. Sign in at https://notebook.google.com/ with your own Google account.
2. Open the linked notebook. A shareable viewer link does not grant editing;
   use the owner's account or invite a specific Google account as Editor.
3. Upload `RESEARCH-PACK.md` from this folder as a source. The same pack can
   be downloaded from the separate Glub tab.
4. Add the starter YouTube URLs listed in the pack as separate sources.
   The inventory file alone does not import their transcripts.
5. Paste the working prompt from the pack into chat. Choose one category
   for the first research session and review its citations and candidate table.

The pack is generated from existing source libraries by `researchPack.js`;
the download on the Glub board reflects those libraries at build time. The local
Markdown snapshot was prepared September 5, 2026. Inline Politics sources are
explicitly included and need updating when that content changes.

Only the owner-supplied notebook URL is stored; no Google credentials or API
keys are stored here. No source material has been uploaded to Google in this session.

Google's current source instructions:
https://support.google.com/gemininotebook/answer/16215270?hl=en
